# 🚗 Car Make Management App

A simple CRUD (Create, Read, Update, Delete) web application for managing car makes using an API. Built with Node.js, Express.js, and Axios, with an interactive frontend powered by Alpine.js.

## 📌 Overview

This app allows users to:
- Add a new car make
- View all car makes
- Update a car make
- Delete a car make
- Filter specific car data (e.g., `nissansFromCK` function)

Useful for learning and demonstrating API integration, frontend-backend interaction, and data filtering in a practical web app.

## 🛠️ Technologies Used

- ✅ Node.js
- ✅ Express.js
- ✅ SQLite (or in-memory data)
- ✅ Axios (for API interaction)
- ✅ Alpine.js (for frontend interactivity)
- ✅ HTML/CSS (Bootstrap optional)
